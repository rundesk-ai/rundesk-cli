# tasks/

Keep concise briefs only for active multi-turn or delegated work that must be resumed. Name each
`YYYY-MM-DD-<short-topic>.md`, link its canonical source when one exists or name the direct request,
and maintain its scope, definition of done, current state, next action, blockers, delegations, and
observed evidence.

Update the brief in place instead of keeping a progress diary. Remove the brief when the outcome is
closed after promoting durable project facts. Keep small single-turn work and project-owned task
state elsewhere.
