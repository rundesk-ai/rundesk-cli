# What rundesk needs beyond the standard library, installed by install.sh into the install's
# own .venv — never into the machine's Python. An empty file here means no virtualenv is made
# at all, which is the state to return to if a dependency ever stops earning its place.
#
# discord.py is imported by src/channels/discord, and by nothing under src/rundesk/. The
# standard library ships no websocket client and Discord's gateway is websocket-only, so
# reaching it needs one — writable in about 900 stdlib lines, which is a cost this build
# chose not to own. Pinned exactly, because an install that resolves differently on two
# machines is two different products.
discord.py==2.7.1
