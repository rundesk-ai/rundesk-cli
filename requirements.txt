# What rundesk needs beyond the standard library, installed by install.sh into the install's
# own .venv — never into the machine's Python. An empty file here means no virtualenv is made
# at all, which is the state to return to if a dependency ever stops earning its place.
#
# discord.py is imported by src/channels/discord, and by nothing under src/rundesk/. The
# standard library ships no websocket client and Discord's gateway is websocket-only, so
# reaching it needs one — writable in about 900 stdlib lines, which is a cost this build
# chose not to own. Pinned exactly, because an install that resolves differently on two
# machines is two different products.
discord.py==2.7.1

# slack_sdk is here on the same terms, and this time the adapter that imports it is here
# too: src/channels/slack, and nothing under src/rundesk/. It was pinned once before a
# Slack adapter existed and taken out again, because a pin is a thing a user pays for on
# every install and every update — it goes in when the adapter that imports it does.
#
# Its *built-in* Socket Mode client implements the websocket protocol itself, so this line
# adds exactly one package and nothing behind it: the aiohttp, websockets and
# websocket-client variants are all optional extras and none of them is installed.
# Verified on 2026-09-02 against a throwaway virtualenv on the Python 3.9 floor:
# `pip install slack_sdk==3.43.0` left slack_sdk, pip and setuptools and nothing else, and
# `slack_sdk.socket_mode.SocketModeClient` resolved to slack_sdk.socket_mode.builtin.client.
slack_sdk==3.43.0
